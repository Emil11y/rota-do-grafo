Vértices: são os círculos do grafo.

Arestas: são as linhas que conectam os vértices.

Pesos: os números nas linhas representam o custo de cada conexão.

Dijkstra: algoritmo utilizado para encontrar o caminho de menor custo em grafos com pesos não negativos.
